# Дринкит · Москва 10

Веб-приложение владельца кофеен: выручка своих точек с процентами изменений, кто требует внимания, разгон новых открытий и табло мотивации по каждой точке. Работает на телефоне как PWA, без бэкенда и без входа: только публичный API Дринкит и официальное табло во фреймах.

## Структура

| Путь | Что это |
|---|---|
| `app/` | Приложение: React + TypeScript + Vite + Tailwind, PWA |
| `app/src/config/units.json` | Стартовый список кофеен владельца |
| `app/public/data/daily.json` | История по дням, её пишет сборщик |
| `scripts/collect.mjs` | Сборщик истории без сервера, запускается GitHub Actions раз в сутки |
| `.github/workflows/collect.yml` | Расписание сборщика, 03:40 по Москве |
| `.github/workflows/pages.yml` | Сборка и публикация на GitHub Pages при каждом пуше |
| `PLAN.md`, `API-NOTES.md` | План проекта и проверенные факты по источникам данных |
| `prototype/` | Проверочные страницы встраивания табло |

## Локальный запуск

```bash
cd app && npm install && npm run dev
```

Сборщик вручную:

```bash
node scripts/collect.mjs
```

## Публикация

1. Создать публичный репозиторий на GitHub, например `drinkit-10`, и запушить в него ветку `main`.
2. В настройках репозитория: Settings → Pages → Source: GitHub Actions.
3. Дождаться workflow `deploy-pages`. Адрес будет вида `https://<логин>.github.io/drinkit-10/`.
4. Открыть адрес в Safari на iPhone → Поделиться → На экран «Домой».

Сборщик начнёт работать сам по расписанию. Первый запуск можно сделать вручную: Actions → collect-history → Run workflow.

## Откуда данные

- `publicapi.drinkit.dodois.io/ru/api/v1/OperationalStatisticsForTodayAndWeekBefore/{id}`: сегодня, вчера, тот же день недели неделю назад, в том числе «к этому часу». Поле `weekBefore` это сегодня минус 7 дней.
- `motivationboard.drinkit.dodois.io/#/board/643/{uuid}`: табло мотивации, встраивается фреймом.
- История по дням копится из тех же ответов: сборщик каждую ночь записывает «вчера» и «неделю назад» по всем точкам подразделения «Москва 10».

Подробности и ограничения в [API-NOTES.md](API-NOTES.md).
